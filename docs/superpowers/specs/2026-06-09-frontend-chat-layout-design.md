# 前端对话流布局重构设计

**日期**: 2026-06-09  
**状态**: 设计中

---

## 目标

将当前手机壳卡片式联调页重构为类似 ChatGPT / 微信风格的全屏对话流页面，同时统一枚举、公司名称、地址选择三种 agent 内嵌卡片的展示风格。

## 现有问题

1. `.phone-shell` 430px 宽度限制不适合桌面端调试
2. Hero 头部始终占位，对话开始后浪费空间
3. 枚举卡片、公司卡片、位置卡片风格不统一
4. 消息流被 `display: grid` 污染（上轮 sed 误伤）

---

## 设计

### 1. 页面状态：两阶段切换

| 阶段 | 条件 | 布局 |
|------|------|------|
| **欢迎态** | `messages` 为空（无对话） | 居中 hero + 底部语音栏 |
| **对话态** | 首条消息发送后 | 紧凑顶栏 + 消息流 + 底部语音栏 |

**切换规则：** `resetSession()` 回欢迎态，`sendMessage()` 首条成功后切对话态。

### 4. 统一卡片设计

所有 agent 卡片继承 `.agent-inline-card` 基类：

| 卡片 | 特有元素 | 确认按钮 |
|------|----------|----------|
| 枚举 | 多列 select 下拉 | "确认这些字段" |
| 公司 | 候选下拉 + 手动输入框 | "确认该经销商名称" |
| 位置 | 候选列表 + 详细地址输入框 | "确认位置" / "跳过" |

**卡片通用样式：**
- 白色背景，24px 圆角
- 浅蓝边框 `#dde6f7`
- 轻阴影 `0 10px 24px rgba(17,24,39,0.06)`
- 顶部状态 pill（蓝底白字圆角标签）
- 底部操作区（flex wrap, gap 10px）

**状态 pill 颜色：**
- 枚举：蓝色 `#eef4ff` / `#21469a`
- 公司：蓝色（同枚举）
- 位置：蓝色（同枚举）

**卡片字段布局：**
- `.card-field-list` 使用 `grid-template-columns: repeat(auto-fill, minmax(150px, 1fr))` 多列排列
- 不仅限于枚举卡片，公司/位置卡片的多字段区域也共用此规则

### 5. 消息气泡

- 全宽容器，气泡 `max-width: 720px`
- agent 气泡左对齐（`align-self: flex-start`）
- user 气泡右对齐（`align-self: flex-end`）
- 卡片与 agent 气泡同侧左对齐

### 6. 底部语音栏

- 固定在视口底部（`position: sticky` 在 flex 容器内）
- 语音大按钮 + 键盘切换小按钮，保持现有交互
- 键盘输入框默认隐藏，切换后展开

### 7. CSS 变量体系（保留）

```css
--bg, --panel, --ink, --muted, --line, --brand, --brand-soft, --accent, --accent-soft, --success, --shadow
```

---

## 不变的部分

- 所有 JS 逻辑：消息收发、卡片渲染（`renderEnumCard`、`renderCompanyCard`、`renderLocationCard`）、语音识别、API 调用
- 后端 API 接口
- HTML template 结构（保留 id 和 data 属性不变）

## 实施要点

1. 从 CSS 层面改，不破坏 JS 选择器
2. `.messages` 的 `display: grid` contamination 需要修复回 `display: flex; flex-direction: column`
3. 先修复样式损伤，再叠加新布局
4. 自测三种卡片渲染 + 欢迎态/对话态切换
